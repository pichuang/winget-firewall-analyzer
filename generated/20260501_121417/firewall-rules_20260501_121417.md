# winget Azure Firewall Policy 規則清單

> 此文件由 `main.py` 自動產生，記錄每個 winget 套件所需的防火牆放行規則。
> 可作為維護與審閱的依據，建議納入版本控制。

## ⚙️ Azure Firewall Policy 部署資訊

| 參數 | 值 |
|---|---|
| Rule Collection Group | `winget-rules` |
| Rule Collection | `winget-download` |
| Priority | `500` |
| Source IP Groups | `ipgroup-corp-clients, ipgroup-dev-clients` （主要） |
| Source Addresses | `10.0.0.0/8` （備用） |
| 規則總數 | 10 |
| 分析時間 | 2026-05-01 12:14:17 UTC+08:00 |

**快速部署參考**：

```bash
# 套用所有規則（JSON 格式）
python main.py WSL.Ubuntu-20.04 WSL.Ubuntu-22.04 WSL.Ubuntu-24.04 WSL.Ubuntu-26.04 -f json > generated/rules.json

# 產生 Azure CLI 部署指令
python main.py WSL.Ubuntu-20.04 WSL.Ubuntu-22.04 WSL.Ubuntu-24.04 WSL.Ubuntu-26.04 -f cli > generated/deploy.sh
```

### 維護建議

- 建議定期重新執行分析，確認套件版本更新後下載路徑是否變更
- 若有新版本發佈，重新產生規則並比對差異：
  ```bash
  python main.py WSL.Ubuntu-20.04 WSL.Ubuntu-22.04 WSL.Ubuntu-24.04 WSL.Ubuntu-26.04 -f md > generated/firewall-rules-new.md
  diff generated/firewall-rules.md generated/firewall-rules-new.md
  ```
- 版本號已正規化為萬用字元 `*`，多數情況下版本更新不需修改規則
- 若安裝檔的下載來源（FQDN）變更，則需更新防火牆規則
